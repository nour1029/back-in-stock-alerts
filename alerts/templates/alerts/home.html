{% icon "bell" 14 %}Back-in-stock alerts

Never lose a customer to “sold out” again.

This demo store shows the alert widget the way shoppers see it. Pick any sold-out product below and ask to be notified. You’ll get exactly one email when it really comes back.

  1. 1Shopper leaves their email on a sold-out product.
  2. 2Your inventory system sends a stock webhook. We verify it against the live stock API.
  3. 3One email goes out per shopper, even if webhooks repeat or the network fails.

<script>
  // Optional: let the widget size itself.
  addEventListener("message", (e) => {
    if (e.data?.type !== "back-in-stock:resize") return;
    for (const f of document.querySelectorAll("iframe"))
      if (f.contentWindow === e.source) f.style.height = e.data.height + "px";
  });
</script>
